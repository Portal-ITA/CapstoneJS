# Init

## `Capstone.init(options:Object)`

`Capstone.init` provides initial options to Capstone. These are used to format and customise how Capstone runs.

Some properties can be provided to init but not to [set](/api/methods/set):

- cloudinary config
- auth
- nav
- mongo
- module root
- app
- mongoose
- frame guard

The initialization options can be found in the [configuration](/documentation/configuration) documentation.

For information on setting up Capstone, see the [installation guide](/getting-started/setting-up/part-1)
