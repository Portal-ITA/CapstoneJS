# Guides

These Capstone guides have been written both to get you set up with Capstone, as well as help explain the concepts Capstone is using, to help you understand how to get the most out of your project.

If you are coming from Capstone 0.3, and are looking to upgrade to Capstone 4.0, read through our [upgrade guide](/guides/v-0-3-to-v-4-0-upgrade-guide)
If you are planning on starting with the Capstone generator, the [yo generator](/getting-started/yo-generator) is the best place to begin, and will walk you through the parts of the generator so you can understand your new project.

If you want to implement Capstone from scratch without the generator, the [setting up](/getting-started/setting-up/part-1) is the best place to start.

Our other guides deal with more specific topics that not every Capstone user will need, however which deserve a bit more explanation than just an API reference.

- [Sending Emails with Capstone](/guides/how-to-send-emails)
- [Creating a blog with Capstone](/guides/how-to-create-a-blog-with-capstone)
